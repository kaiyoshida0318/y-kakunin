# 確認くん｜ヤフショ表示チェッカー

楽天用の縦長画像が、Yahoo!ショッピング（ヤフショ）だとどう見えるかを確認するためのツールです。

ヤフショは画像を **1:1（正方形）** に収めて表示するため、楽天用の縦長画像を入れると **左右に黒帯** が入ります。このツールに画像をドラッグ＆ドロップすると、その見え方をその場で確認できます。

## 使い方

1. ページを開く
2. 画像をドラッグ＆ドロップ（またはクリックして選択）
3. ヤフショでの見え方（黒帯付きの正方形）がすぐ表示されます

- 画像は **ブラウザ内だけ** で処理され、どこにもアップロードされません（安全）
- インストール不要。リンクを開くだけで使えます
